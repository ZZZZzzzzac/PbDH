# SealChat 实验接入

- 仅通过宿主提供的 Channel Embed SDK 通信，不复制 SDK、不读取 token、不调用内部 HTTP API。需授予 context.read、characters.read、characterCard.read、messages.send；characters.read 用于活动消息身份及切换保护。官方读卡仍按账号读取 Dice 活动卡，不假设场内/场外身份各有一张 Dice 卡。
- Platform 仅在同源导航中保留入口的 sealchat、hostOrigin、sdkUrl 三个参数；市场查询与一次性交接参数不沿用，不向外站传递接入设置。玩家功能的“与海豹聊天连接”打开或恢复面板并重连，不初始化资源；独立网页只显示正确入口说明。
- 匕首之心专用字段映射仅属于此适配器，不进入 System Package Contract 或通用角色存档模型。
- 经用户明确调整，PbDH 当前 Character Save 是属性、经历、装备和持久化资源的来源。iframe 的账号、导入、本地保存和云同步复用正常 Platform/Runtime，不另建存档或手动云保存接口。
- 明确关联通过实验 .dh pbdh 可读中文 JSON 指令初始化资源、存档 UUID 和人物昵称；普通汉字直接显示，仅对 <、>、& 作 JSON 字符转义。姓名取 Character Data 的 character-name 字段，空白回退为未命名角色。DHPbDH姓名 是昵称确认标记，不改 Dice 绑卡元数据。确认回读来源、姓名及所有资源后通过 Runtime 字段更新保存资源；普通模式保持原有行为，不改变系统包皮肤和布局。
- 未标记规则类型的活动卡允许显式关联，sealpack 初始化仍在写入前校验群规则；已有其他规则卡拒绝。原生 .st 为未标记卡填入 DH 类型不打断关联。登录、连接、发送权限、类型与 SDK 授权显示具体原因。
- 闪避、重伤阈值、严重阈值以 PbDH 为准，关联时写入，编辑或 Dice 外部变化后单向同步并回读确认；不反写人物存档。零与未知严格区分，无效值停止关联，不清零。
- 资源步进发送相对 .st；PbDH 原生编辑引起的资源变化仅同步变化字段。回读不会触发反向重复写入；等待结果期间的较新本地修改不能被旧结果覆盖。
- 关闭重开或断线后可显式重连：核对当前 Dice 的 DHPbDH来源 UUID、DHPbDH姓名 与 PbDH 当前人物，校验权限与资源后只读取 Dice 当前资源恢复会话，不发送 .dh pbdh，不自动回退初始化。首次或标记不匹配仍需明确初始化；重连期间较新的本地资源编辑保留。
- 切换存档、身份、频道、来源标识或断线后重新确认关联或重连；草稿携带关联令牌。宿主缺少原子 expectedCardId/版本比较，不宣称严格外部 .st 并发安全。
- 六特质、主副武器使用独立 🎲 按钮，属性原点击保留编辑。除闪避、重伤阈值、严重阈值供徽标使用外，其他基础数据不写 Dice；掷骰生成数值 .dd/.ddr，经历修正内联，hope=费用由实验 sealpack 校验并与掷骰结算。掷骰消息不携带 pbdh=UUID；桥接层发送前通过官方读卡核对 DHPbDH来源。实验 sealpack 仍兼容旧 pbdh 参数，读卡与发送之间不具备原子性。
- 原生非 iframe 人物卡的 DH经历/exp 协议继续兼容，不因本实验改变已发布版本。
- 伤害读取 PbDH 武器和熟练度，三个输入及显式 DamageAdjustment 接口组合 .r；发送前核对源快照，不推断特性自然语言。
- 测试替身只供隔离预览，不打包，不向正式云端创建、修改或回收合成文档，不连接生产 IM。
