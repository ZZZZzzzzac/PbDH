# SealChat 实验接入

- 仅通过宿主提供的 Channel Embed SDK 通信，不复制 SDK、不读取 token、不调用内部 HTTP API。
- 匕首之心专用字段映射仅属于此适配器，不进入 System Package Contract 或通用角色存档模型。
- 经用户明确调整，PbDH 当前 Character Save 是属性、经历、装备和持久化资源的来源。iframe 的账号、导入、本地保存和云同步复用正常 Platform/Runtime，不另建存档或手动云保存接口。
- 明确关联时仅将资源当前值、上限和 DHPbDH来源 存档 UUID 写入 Dice。确认回读后通过 Runtime 字段更新保存资源；普通模式保持原有行为，不改变系统包皮肤和布局。
- 资源步进发送相对 .st；PbDH 原生编辑引起的资源变化仅同步变化字段。回读不会触发反向重复写入；等待结果期间的较新本地修改不能被旧结果覆盖。
- 切换存档、身份、频道、来源标识或断线后重新确认关联；草稿携带关联令牌。宿主缺少原子 expectedCardId/版本比较，不宣称严格外部 .st 并发安全。
- 六特质、主副武器使用独立 🎲 按钮，属性原点击保留编辑。基础数据不写 Dice；检定生成数值 .dd/.ddr，经历修正内联，hope=费用由实验 sealpack 校验并与掷骰结算。pbdh=UUID 由桥接层附加，sealpack 在投骰前核对来源。
- 原生非 iframe 人物卡的 DH经历/exp 协议继续兼容，不因本实验改变已发布版本。
- 伤害读取 PbDH 武器和熟练度，三个输入及显式 DamageAdjustment 接口组合 .r；发送前核对源快照，不推断特性自然语言。
- 测试替身只供隔离预览，不打包，不向正式云端创建、修改或回收合成文档，不连接生产 IM。
