# 三灯系统包 0.1.0

开发中的独立系统包，仅含一张人物卡。按 [GitHub Issue #81](https://github.com/ZZZZzzzzac/PbDH/issues/81) 的手绘批注稿制作，母版为内置包 `heart-of-hopefind` 的纸张人物卡布局；两者互不替换。

按“红字整段替换黑字”的批注读法：「代称」改为「年龄」，「生命」改为「性别」，「压力」改为「情绪缺陷」；「希望点」改为「阳气点」，「受伤点」整行划掉删除。姓名、年龄、性别、情绪缺陷四个基本信息都是自由文本。

## 交付物

- 可导入系统包：[san-deng-0.1.0.pbsys](../san-deng-0.1.0.pbsys)。在 Player 的“系统包 → 上传系统包(.pbsys)”中导入。
- 可编辑源目录：`apps/player/system-package-sources/san-deng/`。
- 系统身份：`01a1976b-4189-7f77-83a3-64d7cd0211d5`。本包不内嵌资源包，也不登记为内置预设。

## 与设计图不一致的取舍

- 原“求生者风格”框右上角的资源选择按钮未保留：本包没有内嵌资源库，按钮会打开空列表。
- 设计图把“受伤点”整行划掉，按删除处理；“希望点”被红字改写为“阳气点”，沿用星形标记。
- 弧光五条与强度改为默认隐藏的兼容字段：旧存档里的弧光内容保留，页面不再显示“弧光”。
- 噪音、暗蚀改为默认隐藏的兼容字段：页面不再显示，旧存档里的勾选状态保留。
- 旧存档已经写入“受伤点”（`yang-points`）状态，因此该模块保留为默认隐藏的兼容字段：页面不显示，但旧存档仍可加载；新存档也会带一个隐藏的 0 值。
- 三盏灯把“亮灯规则”和“灭灯记录”分成两个模块：点亮时显示只读规则，熄灭时显示独立的长文本编辑框。灭灯输入保存在 `sky-lamp`／`yang-lamp`／`yin-lamp` 中，切换开关不会覆盖。
- 人物数据版本 0.1.3：0.1.0 → 0.1.1 把「性别」「情绪缺陷」的计数对象转成文本；0.1.1 → 0.1.2 给旧存档补空的「角色背景故事」；0.1.2 → 0.1.3 把三盏灯的「亮/灭」文本转成开关状态。系统包版本仍为 0.1.0。
- 阳气骰、阴气骰的档位由图中范围写法推断为下拉选项；若规则另有档位，只需改 `modules.json` 的 `选项`。
