# 潜相心影：都市异闻录系统包 0.1.14

作者统一为 **P心制作组**，译者为“无”，许可为“未声明许可”。本版把人物卡的“体力”改称“心力”，并在宫殿区加入人格面具姓名栏。上一版补入 2026-10-27 读取的宫殿草稿，供本地试用，未公开发布。

## 交付物

- 可导入系统包：[persona-heart-0.1.14.pbsys](../apps/player/system-package-sources/persona-heart-0.1.14.pbsys)。在 Player 的“系统包 → 上传系统包(.pbsys)”中导入，并确认脚本与人物数据升级。右键卡牌使用“翻面”切换日常／宫殿；人物卡技能框上方的“添加技能”可选择元素技能并追加正文，原技能文字仍可手动编辑。
- 可编辑源目录：`apps/player/system-package-sources/persona-heart/`。作为独立系统包开发，不修改主站代码或内置包注册表。
- 内嵌资源包：`apps/player/system-package-sources/persona-heart/resources/persona-heart.pbres`，版本 0.1.7，使用现有 `自由@1.1.0` 模板。
- 系统身份：`01a17c40-0000-7000-8000-000000000001`；资源包身份：`01a17c40-0000-7000-8000-000000000002`。

## 已确认的规则与操作

- 0.1.14 把人物卡资源栏的“体力”改称“心力”：仅改显示标签与创建向导说明，模块 ID 仍为 `stamina`，底层数值和已有存档不变。宫殿区新增姓名栏（`persona-name`），用于填写人格面具的名字，位于宫殿标题行与立绘之间；创建向导的“非日常设计”步骤同时说明该栏。资源包、卡面正文和人物数据版本（0.1.6）均未改动。
- 0.1.13 补入 14 个原空白宫殿面的正文；魔术师两面已有正文保留。用户确认以独立日常文档区分来源，因此宫殿文档隐者段落中的“日常卡面”不用于覆盖日常面。风、水、土、火各两项一级资源是技能，不是小阿卡纳；通过“添加技能”追加至现有技能框，不自动分配、不替换手填内容。未改人物数值或自动执行技能效果。人物数据升至 0.1.6，已有存档中仍为原包正文的宫殿正／背面副本补齐内容，手改正文保留。
- 0.1.12 恢复 32 个卡面的“阶段：日常／宫殿”标签；继续使用“正位・皇帝”等卡名，不恢复“牌位”标签。人物数据版本升至 0.1.5，为已有本包卡牌副本补回阶段，其余正文、名称、状态、位置和形态关联保持原值。
- 0.1.11 将 32 个卡面的名称统一为“正位・皇帝”“逆位・皇帝”等形式，日常与宫殿两面同名；移除模板 `data` 中的“牌位”“阶段”，不再显示重复标签。资源 ID、目录和形态关联保持不变，正逆位选择按钮分别用稳定 ID 筛选对应的 8 张日常卡。人物数据版本升至 0.1.4，已有本包卡牌副本同步改名并移除两个字段，保留其余正文、位置、状态及关联。
- 0.1.10 仅更新独立系统包：将 32 个卡面的 `data.另一面` 改成现有 PBRES 形态关联，移除桌面的旧背面字段映射；布局、规则正文、资源 ID、媒体与署名保持不变。人物数据版本升为 0.1.3，升级已有存档中的本包卡牌副本：去掉旧标签、补齐形态关联，保留实例 ID、位置、旋转、缩放、状态与指示物，并把原先翻到背面的卡转换为对应的当前形态。未翻面卡牌保留玩家编辑过的正文，旧背面采用原包相应卡面；其它包卡牌不动。
- 0.1.9 仅修正 32 条“另一面”引用为现有主站要求的完整条目 ID。布局、规则文字、资源 ID 和人物数据版本保持不变。本任务此前引入的主站校验器、翻面解析、立绘组件、内置注册和相关测试改动均已撤回，相关临时材料保留在 `.scratch/persona-withdrawn-host-changes/`。
- 0.1.8 修正立绘方向：两处均采用等大的竖向画框，以原宫殿立绘为参照；日常与宫殿各占人物页一半，控件排在立绘右侧，保持经历行高。方形与竖长图片均完整适配画框。
- 0.1.7 将两处立绘统一为相同宽度和 12rem 高度；宫殿数值排在立绘右侧，技能栏改为下方通栏，人物卡和卡牌桌面仍等高。
- 0.1.6 将人物卡独立排为 210 × 297 mm 的 A4 竖页，桌面右侧占满剩余浏览器宽度，与人物卡等高。四属性和战斗数值改为紧凑横排，日常立绘与五行经历并排，宫殿立绘与技能栏填满下半页；经历保持 32 px 行高及原修正栏尺寸。打印时人物卡、卡牌区各自分页。窄屏改为上下排列，人物数据版本保持 0.1.2。
- 0.1.5 将两个阈值合并显示在“阈值”框中，格式为“重度 / 严重”，两侧仍可分别编辑；体力控件去掉“剩余”字样。所有底层字段和已有数值保持不变。
- 0.1.4 移除页面上的非日常类型框，将战斗预设选择按钮放到宫殿标题行。希望、剩余体力、金钱合为三行资源表，统一标签列和加减按钮位置，金钱分成三等宽单元。原预设记录继续留在存档中，人物数据版本不变。
- 0.1.3 将经历改为五行名称／修正值，并放大四属性与宫殿数值控件，填满立绘旁的高度；希望、体力、金钱与经历区底部对齐。人物数据版本升至 0.1.2，旧补充经历保留到第三行，新增三行的修正值默认留空。
- 0.1.2 的人物卡采用匕首之心／tttri 的紧凑控件形式：细分隔线、突出属性值、经历输入行、右侧金钱单位和战斗预设图标按钮。移除页面解释段落、试跑标语及说明性占位文本，规则指引保留在创建向导与审核中；人物数据版本仍为 0.1.1。
- 心力初始为 6，表示剩余心力，消耗时减少；本版默认上限也为 6，可手动调整。该栏在 0.1.14 之前显示为“体力”。
- 三套非日常预设选择后一次性填入数值并回满生命；后续手改值在保存、重开及运行时重建后保留。
- 正位大阿卡纳、逆位大阿卡纳和小阿卡纳共用一个自由桌面；正位和逆位是两张独立卡，各自支持日常／宫殿翻面。

- 小阿卡纳按钮仍打开小阿卡纳类型选择器，当前无资源；元素技能由人物卡内独立选择器追加到技能框，仍可手填。

- 金钱“张／叠／箱”独立记录，本版不推定换算规则。0.1.5 修正最后一个单位的显示名称，保留已有数值。进入宫殿后的生命恢复由玩家手动执行。
