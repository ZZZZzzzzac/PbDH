# PbDH 图文速查

**车卡看第 1 节；做卡看第 2 节；带团看第 3 节。** 手机用右上角三横线切换页面。

## 1. 玩家：从建卡到开团

**选「系统包」→「玩家存档 → 新建人物」→「玩家功能 → 创建向导」→ 填卡。**
也可用「问卷创建」推荐角色；填完点「车卡审核」。向导和问卷仅在部分系统提供。

> **图 1**：玩家顶部三个菜单展开图，圈出选系统、新建、向导、审核。

### 记住这几个操作

- **改文字**：直接点文字，支持markdown语法与染色（:red[文字]，orange、yellow、green、blue、purple、gray）。
- **资源栏**：左键点 `+ / -`改当前值；右键点 `+ / -`改最大值。手机长按约半秒等于右键。数字式直接改数字。
- **选职业、装备、能力**：点对应选择按钮，搜索或用漏斗筛选、箭头排序，再点选条目；多选最后点「确认选择」。分步选择要全部选完。
- **选兼职**：匕首之心在第二页下面点「兼」。升级、伙伴、背景在对应页面填写；方框点击勾选／取消。

> **图 2（重点）**：同一计数器左右对比，左图「左键 +：多标记一格」，右图「右键 +：多一个总格」。箭头指按钮，不指格子。

### 用卡与加卡

- **卡牌可拖动**；右键／手机长按可看详情、翻面、旋转、换形态、标记状态或删除，按该卡支持的菜单操作。
- **指示物**：卡牌菜单添加；左键加数、右键减数，手机对应轻点／长按；0 时再减即移除，最多 10 个。
- **整理布局**：点「整理」，滑杆调卡牌大小；拖桌面底边改高度，双击恢复。
- **装资源**：
  - 在线安装：去「资源市场」找到资源包，点击「安装到玩家」，会自动导入「资源管理器」。
  - 本地安装：「玩家功能 → 资源管理器」上传 `.pbres`，或第三方来源格式（支持dhcb、rink、不咕鸟等格式）；这里也能搜索、预览、更新和移除包。

**安装后还要回人物卡选用。找不到时检查「其他资源」；更新资源不会自动覆盖已填人物或桌面卡。**

> **图 3**：玩家卡牌右键菜单、指示物和资源管理器导入按钮，各截局部。

### 存档与输出

「玩家存档」可切换、重命名、复制、删除人物；「系统包」换规则不删旧人物。

「导入导出」中：**`.pbcha` 用于备份和继续编辑**；HTML 用于浏览；PDF 进入打印窗口另存；海豹骰指令复制后粘贴到聊天。
第三方人物格式按菜单选择，先看转换报告；遇到覆盖冲突，拿不准就「另存为副本」。

## 2. 创作者：制作与分享卡牌

**「卡牌工坊」→ 新建资源包 → 新建资源、选模板 → 填内容 → 看右侧预览。** 没有合适模板就选「自由」。

> **图 4**：工坊全景，圈出新建包、新建卡、字段预设箭头、卡图、卡面模式和发布。

- **编辑**：字段小箭头选预设，也可手填；特性可新增、清空、删除；署名在「卡面署名」填写。
- **卡面**：切换纯文字／图+文／纯图片；关「固定比例」可用可变高度。卡图可添加、更换、重新裁剪、删除；裁剪时拖框／四角、滚轮缩放。
- **整理**：新建文件夹，拖资源入目录；右键资源复制、跨包复制或删除；「多选」后右键批量操作。
- **查找**：左侧搜文字，也可输入 `[模板:敌人]`、`[位阶:1]`；不同字段同时满足，同字段多个值任选其一。
- **标签页**：双击资源固定标签，拖标签排序；拖栏间分隔线改宽度，双击恢复。
- **换形态**：「换卡」选同包目标；要往返就互相设置。GM 换卡保留布局，但重置战斗记录；来源包与目标须保留。
- **文件**：工具栏导入／导出 PBRES、dhcb、ZZZ、Rink、不咕鸟格式；先选来源，看报告再确认，备份优先 PBRES。
- **包设置**：右键包编辑信息、升级模板；**「删除资源包」会移入回收站**，不是关闭标签。
- **同 ID 重新导入**：工作区优先。明确导入会替换本机回收站中的同 ID 旧副本，保存成功后才载入；云端回收站中的同 ID 旧包不会删除本地工作区。
- **恢复与并发编辑**：回收站恢复不能覆盖已有同 ID 工作区。后台处理期间继续编辑时，优先保留当前编辑；遇到版本变化提示，先导出当前内容备份，再确认后续操作。
- **发布**：登录 →「发布到资源市场」→ 填封面、简介、标签、许可、目标系统 → 确认版本后发布。改卡后需重新发布。

## 3. GM：摆卡与记录战斗

**「GM 桌面」→ 标签旁 `+` 建桌 → 从左侧资源树拖卡进去。** 也可右键资源放到当前桌面，多选后批量放置。

> **图 5**：拖卡箭头、敌人生命／压力格、卡牌菜单；再截桌面空白处的右键菜单。

- **摆卡**：拖动移动；选中后拖缩放柄调大小；`Ctrl / Command` + 点击多选。
- **看桌面**：中键／右键拖空白处平移，触屏直接拖；`Ctrl + 滚轮` 或右下角按钮缩放；「适合内容」找回卡牌。
- **战斗**：点敌人生命／压力格记数，点最后一格退一格；特性标题前 `+ / -` 展开／收起。
- **改卡**：右键／长按卡牌，可查看、编辑、换形态、旋转、翻面、复制、删除。**修改只影响这一张，不改工坊原卡。**
- **管桌面**：右键标签或空白处，可重命名、复制、整理、扩大、清空、打印、导入／导出 `.pbtab`、同步或删除。

**桌面标签叉号是删除。清空前先导出备份；单卡删除、清空布局不能单独从回收站找回。**

## 4. 市场：取得别人的资源

**搜索 → 筛选／排序 → 点资源包 → 看包内卡牌，点「放大」看清。** 点作者看其作品；「复制当前链接」分享。

> **图 6**：资源详情的取得按钮；作者视角补截编辑信息、取消发布按钮。

- **安装到玩家**：确认安装，再回人物卡选用。
- **导入卡牌工坊**：取得后编辑；**Fork 草稿**用于保留来源的改编。
- **发送到桌面**：跳转后，还要从左侧把卡拖到桌上。
- **下载 .pbres**：保存文件。以上取得的都是**整包**，不是单张。
- **自己的发布**：详情页可编辑介绍、升级模板、取消／重新发布；永久删除需先取消发布。改卡正文要回工坊。

## 5. 保存：别等换设备才找备份

点右上角账号注册／登录。**登录前的旧文档要手动「同步到云」**：人物在「玩家存档」，资源包／桌面在各自菜单。登录后新建或导入文档自动同步，换设备前确认完成。

> **图 7**：圈出同步状态、账号内云空间明细、顶部回收站。

- **云冲突**：可选云端、本地覆盖或本地另存；不确定选另存。另一设备接管后，点「在此设备继续」恢复云写入。
- **查空间／退出**：账号窗口操作；**恢复删除**：顶部回收站，文档保留 30 天，永久删除不可撤销。
- **文件别混**：人物 `.pbcha`、资源包 `.pbres`、GM 桌面 `.pbtab`、规则系统 `.pbsys`。玩家桌面跟人物一起保存，系统包和已安装资源需另备。
- **自定义规则**：「系统包」上传 `.pbsys` 或文件夹；人物「待匹配」先补对应系统，只运行可信来源脚本。
