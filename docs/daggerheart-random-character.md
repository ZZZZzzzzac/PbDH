# Daggerheart 完全随机

玩家功能菜单中的“完全随机”创建并切换到一个新的1级角色。原人物先完成保存；生成失败或审核存在警告、错误时不写入候选人物。

Player 预置系统目录通过可选 `randomCharacterGenerator` 接口注入可信生成器。公共创建流程只负责候选、审核、保存及切换，游戏规则由实现负责。目前仅内置 `daggerheart-core` 注册，其他预置系统与作者预览没有入口；不增加系统包 Contract 字段。

抽取范围为当前已加载的内置核心玩家资源包：单一种族、社群、九个职业、所属职业的基础子职，以及该职业两个领域中的不重复1级卡。通常抽2张领域卡，知识学派抽3张。第三方或扩展资源不进入本功能的随机池。

职业资源的推荐属性与装备优先使用；核心资源的这些字段目前为空，因此提供九个职业的缺省配置。同时填写“一条战斗相关经历”和“一条非战斗相关经历”两个占位名称，基础调整值均为 +2，供玩家后续改成自己的经历。械灵的第一项经历额外 +1。计算种族、子职、装备、配置中的领域卡带来的永久修正。新角色未标记生命、压力和护甲槽，保留系统默认希望及金币。
