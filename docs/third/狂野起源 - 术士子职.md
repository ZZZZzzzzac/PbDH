# 狂野起源 \- 术士子职

**作者**：草方块

|### **基础特性**<br>**狂野魔法浪涌：**你施法时会不经意间流露出未经塑造的魔法浪涌。每当你以恐惧成功的结果激活领域卡上的魔法效应时，DM都可以要求你立刻投掷一颗D4：<br>- 投掷结果为1：根据“狂野魔法浪涌表”骰出随机的魔法效应。<br>- 投掷结果为2：立刻标记1D4的压力点，本场景内你不再触发狂野魔法浪涌。  ●投掷结果为3：你与近距离的友方获得2希望点，GM立刻获得D4恐惧点。<br>- 投掷结果为4：你可以主动标记1压力点使得该次魔法效应翻倍！（由你和GM共同商议）<br>**塑造混沌**：每场游戏开始，你投掷等同于施法属性点数的D4骰（至少为1），每颗骰子都可以用于增加或减少你的恐惧骰点数。|
|---|
|### **进阶特性**<br>**混沌施法：**你因为激活领域卡的魔法效应而使用熟练度投掷伤害骰时，熟练度改为D12\-3。当D12结果高于6时，你的投掷结果视为恐惧成功。<br>当你激活狂野魔法浪涌时，可以选择额外投掷一次，但你必须接受第二次投掷的结果。|
|### **精通特性**<br>**混沌裁定：**每当你出现恐惧结果时，你都可以选择触发狂野魔法浪涌。<br>你投掷的恐惧结果不再会产生恐惧点。<br>当你激活狂野魔法浪涌的随机魔法效应选项时，你可以通过标记对应的压力点来增加或修改D100的出目，以此修正狂野魔法浪涌表产生的结果。|
