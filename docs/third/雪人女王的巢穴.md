# 导言 

雪人女王的巢穴既可以作为单场游戏冒险，也可以作为独立地点放入你的战役世界。本冒险适合位阶 2 玩家角色。

雪人女王嗜血、残忍，又狡诈。邻近的雪人部族中，有不少人乐意见证她倒台；附近村庄的居民也会因为她死去而睡得安稳些。另一方面，她也可能成为这片无情土地上的一名强大盟友。

### 目录

- 第 1 部分：夜袭者。一个可选的开场遭遇，用来引导玩家角色踏上寻找雪人女王的旅程。

- 第 2 部分：雪人女王的巢穴。一个附带区域标注的地城，详细介绍雪人们的巢穴、非玩家角色描述和物品属性。

- 第 3 部分：敌人数据块。包括雪人游荡者、雪人嚎叫者、雪人雪橇骑手、雪人憎恶与雪人女族长。

# 夜袭者

玩家角色在镇子另一头的爆炸声中惊醒。约一分钟后，刺耳的尖叫和急促的警钟接连响起。等玩家角色赶到现场时，袭击已经全面展开。1 名雪人嚎叫者、1 名雪人憎恶、2 名雪人雪橇骑手，以及数量等同于玩家角色人数的雪人游荡者，正在城门附近与卫兵交战。

## NPC

### 奥库巴\-扎库，女王

*\(Oh\-koo\-bah Zah\-koo\)*

雪人女王强大又狡诈，并由来自轮回下界的黑暗魔法所滋养。但真正让她在同族中脱颖而出的，是她的野心。她不满足于在冰封荒野中漫无目的地游荡、猎杀偶尔迷路的旅人；她想占有，想征服，想统治。

她在族群中属于平均体型，毛皮里编织着骨头、硬币和其他战利品，行动时叮当作响。漆黑的阴影自她的獠牙滴落。她挥舞着一把由猛犸象骨雕成、并被恶魔之血染成乌黑的镰刀。奥库巴\-扎库使用雪人女族长数据块。

- 诉求：力量、财富、尊重、恐惧

### 巧手索努希尔

*\(So\-noo\-heel\)*

索努希尔是一名矮壮的雪人，毛发短而斑驳，乳白色的眼睛看不见东西。

他是族群中最出色的工匠，负责制作族群使用的精美毛皮、兽皮、工具和武器。他忠于女王，但对她插手轮回下界的力量不以为然，并担心她的安危。

索努希尔使用雪人游荡者数据块，并额外拥有蒙面盗贼的“逃跑计划”特性。

- 诉求：磨炼手艺、确保族群安全

### 断牙法胡加什

*\(Fah\-hoo\-gosh\)*

法胡加什是族群中最高大的雪人。长而粗硬的毛发垂在肌肉虬结的身躯上，身上交错着锯齿般的伤疤。他是族群中最娴熟的猎手，也是决斗坑中最可怕的斗士之一。他既敬佩女王的力量，也敬佩她冷酷的精明。他梦想有朝一日与她展开一场至死方休的决斗。法胡加什使用雪人憎恶数据块。

- 诉求：战斗、饱餐、痛饮
