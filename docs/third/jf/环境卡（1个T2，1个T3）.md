# 环境卡（1个T2，1个T3）

**钢铁野地**
**位阶2 探索**
如果忽略其中的机械生命体和人造景观，这是一片生态丰富，充满奇迹的美丽田野
**趋向**：吸引好奇者，拓张领地，改变环境
**难度**：14
**潜在敌人**：机械化的其他敌人（详见机械化生命）
特性
**交错景观\-被动**：这片土地上象征自然的景观与人造机械的双方特征互相混合在一起。
一名玩家角色可以进行一次**知识掷骰**来检查人造机械方面的信息或进行一次**本能掷骰**来感受自然方面的气息。
关键成功：获得有价值的信息和一件相关的有用物品。希望成功：获得有价值的信息。恐惧成功：因另一方的干扰获得模糊或不完整的信息。希望失败：**标记1压力点**以在一次追根究底的研究后获得一条线索。恐惧失败：另一方被你的行为激怒，其会尝试报复你。
*双方会给予有关自己的信息还是对方的？双方是如何在田野里彰显自己的力量？如果被激怒，他们会进行物理性攻击还是心理上的折磨？*
**机械化生命\-被动**：此地的敌人均以部分或完全机械化改造的形式出现。
所有**非杂兵敌人**获得**1个额外压力槽**以及**机械造物**特性。
（**机械造物\-反应**：当其**受到伤害时**，其可以**标记1压力点**将**伤害程度降低一级**）
*他们的机械化特征在哪里最为显眼？他们是否对自己的机械化改造满意？他们对其他机械造物有何见解？*
**环境变迁\-动作：花费1恐惧点**，将当前场景变为更加恶劣的状态，如冰川，裂谷，火山等。
*在玩家眼中，环境是如何完成变化的？是更加狂野的自然的变化，还是某种计算下的精密改造？当场景结束后，这种变化会完全保留下来，或是留下痕迹，还是完全消失？*



**机械王座**

**位阶3 险境**

一座高耸的多层建筑，其周遭的一切都已被机械化改造

**趋向**：转化外来者，监视领地活动

**难度**：16

**潜在敌人**：机械造物（机械领主，杀肉刀，寻猎哨卫……），机械化的其他敌人（详见机械化生命）

**特性**

**机械化生命\-被动**：此地的敌人均以部分或完全机械化改造的形式出现。

所有**非杂兵敌人**获得**1个额外压力槽**以及**机械造物**特性。

（**机械造物\-反应**：当其**受到伤害时**，其可以**标记1压力点**将**伤害程度降低一级**）

*他们的机械化在哪里最为显眼？他们是否对自己的机械化改造满意？他们对其他机械造物有何见解？*

**生理厌恶\-被动**：当玩家角色使用自然或天生类型方式进行**动作掷骰**具有**劣势**。

*周围环境是如何表达对这种自然能力的排斥？玩家是否会转而使用非自然的手段？*

**机械化改造\-被动**：如果玩家角色**标记了其最后一个压力点**，其一部分会变得机械化，使用**d20作为恐惧骰**，并对其他**机械造物**的**掷骰具有劣势**。

*这种改变具体如何体现？这种改变是否可逆？你和盟友或是敌人对这种变化作何反应？*

**巡逻队伍\-动作：花费1恐惧**，在**远距离**范围内召唤**一个或数个标准敌人**。

*巡逻队是否注意到玩家？巡逻队是纯粹的机械还是部分机械化？如果是后者，玩家会发现什么熟悉的特征？*

**自启动防御措施\-反应：倒计时（1d4）**。当玩家**掷出恐惧结果时**，启动倒计时，其在触发时，所有仍在场景内的玩家角色必须进行一次**由你选择属性的反应掷骰**，失败时需**标记1生命点和1压力点**。

*这个机关是如何运作的？是否有办法制止这种自动化效果？是否有玩家曾见过类似机关？*
