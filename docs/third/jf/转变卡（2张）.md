# 转变卡（2张）

**半机械化生命**
半机械化生命是被人为或其它手段改造过后的产物。
**改造工程**：游戏主持人立即为你选择**2个未标记的升级选项**并将好处记录在你的角色卡上
**机械共鸣**：当你掷出**希望结果**时，你在这张卡上**放置一个共鸣标记物**而不是**获得1希望点**，**共鸣标记物**的上限为6，如果你获得伤痕，**共鸣标记物**上限\-1。当你需要**花费希望点**时，你必须**花费等量共鸣标记物**作为代替。
**特殊情况下**，游戏主持人可以将盟友或其他效果给予你的希望点转换为等量共鸣标记物。



**视灵者**

视灵者被鬼魂纠缠，并可以看到他们，视灵者们看到的第一个鬼魂，往往是他们的亲人，爱人或是至交

**永不安宁**：**永久划掉1个希望槽**，每当你掷出**恐惧失败**时，GM可以描述周围出现的鬼魂，你必须**标记1压力**或描述你如何反应。

**从未离开：**你拿取一张灵魂同伴表（游侠同伴表），GM为灵魂选择任意个升级选项，代表其曾经的力量，然后你可以GM商议至多等同于你位阶个独特能力，记录下来，这些能力代表你与灵魂之间的相互影响。
