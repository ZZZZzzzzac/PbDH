# 战利品（28个）

**鲜爽水晶 1d12**
一颗手掌大小的蓝色透明水晶，可以使你的身体和身上的携带物保持清洁且不会生锈或变质


**晨露滴管 1d12**
滴管需要新鲜的露水才能发挥出它的魔力中，你可以为一件物品滴上一颗露水，此物品不会由自然原因由产生变质，风化或生锈等影响，一天后，露水会自然蒸发



**美味吸管 1d12**
当你使用吸管喝水时，你可以品尝出一种你选择的风味

**荒野兜帽 2d12**
**每休息一次，花费1希望点**，你可以询问游戏主持人有关该环境生态的问题，例如：
附近有什么大型野兽
最近的天气怎么样
这株植物有什么特点



**匿具护腕 2d12**
你可以额外装备**一把副武器**，但你仍然需要一只空闲的手来使用它攻击或激活它的特性，当你未使用这把武器时，它会隐藏在护腕中以避免被识别为武器

**美味食谱 2d12**
**花费⼀项修整行动**和足量食材来制作**⼀道佳肴**

**预言水晶 2d12**
**每长休一次**，**花费几分钟**专注于水晶后，**花费1希望点**获得一道有关目标未来的模糊预言

**灵视之眼 2d12**
**进行一次施法掷骰（13）**，成功后，**每长休一次**，**标记1压力点**，你可以询问游戏主持人一个问题，游戏主持人会给予你一个视觉性的回应

**悲剧琴弓 2d12**
这把琴弓只需在空气中随意拉动就可以产生优美且悲伤的曲调
**每长休一次，标记1点压力**，所有**近距离**内盟友**获得1希望点**
琴弓可以作为一件T2主手武器使用，具体属性如下：
悲剧琴弓  风度  远距离  d6\+3  单手  悲伤：成功攻击的同时会额外标记1压力点

**飞刀绑带 3d12**
**每休息一次，花费1希望点**从绑带中掏出以下一把飞刀并立即掷出：
**散花飞刀  追魂飞刀  闪光飞刀**

**羽衣披肩 3d12**
**标记1压力点**，你可以飞行，直到你**长休**或受到**严重伤害**

**联心对戒 3d12**
这对戒指必须由两名自愿生物共同佩戴才能发挥作用
两名佩戴者总是可以感知到对方的心情
**每枚戒指，每场游戏一次，花费1希望点**，为另一名佩戴者**清除1压力点**，作为回应，另一名佩戴者也可以**花费1希望点**，为你**清除1压力点**

**小屋模型 3d12**
**花费几分钟**专注于模型，在一片空地中召唤出一间简单但设施齐全的露营小屋，当使用小屋**完成长休后**，所有人**获得1希望点**且小屋无害地变回模型，但如果没有人**执行推进长休项目**并选择小屋作为目标，则在长休后进行一次**反应掷骰**，如果**恐惧骰**更高，小屋会立即崩毁，且模型无法再次使用

你**获得1个额外的压力槽**

**钢骨之刻 3d12**

**命运石 4d12**
当你获得命运石后，与游戏主持人商讨关于你角色的目标或愿望，这在之后的游戏可以随时重新讨论
此外，**每场游戏开始时**，你和所有盟友**获得1希望点**，并掷一个**d12**，记录数字，在本场游戏中，每当你的**希望骰**掷出该数字，你的总结果**\+1d4**；每当你的**恐惧骰**掷出该数字，你的总结果**\-1d4**
当你**进行动作掷骰前**，你可以描述这次行动与你命运的牵联，然后你可以先骰**4d4**，如果有两个骰值相同，这次行动自动视为**关键成功**，一旦你因此获得**关键成功**，你及所有**极远距离**内盟友额外**获得1希望点**并**清除1压力点**，然后命运石失去这项能力
