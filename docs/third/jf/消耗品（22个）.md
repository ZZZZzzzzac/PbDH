# 消耗品（22个）

**寄语落叶 1d12**

在叶子上记录你要传达的信息，你需要标记收信者和收信时间，随后让叶片落到地面，叶片会在你标记的时间立即腐烂，并将信息传递到标记的收信者



**佳肴 1d12**

在**休整**时，**恢复共计2点的生命或压力**



**散花飞刀 2d12**

**标记1点压力**，**邻近距离**内所有敌人必须进行一次**反应掷骰\(13\)**，失败时受到**3d6\+3物理**伤害



**追魂飞刀 2d12**

**标记1点压力**，选择**极远距离**内一个目标，其进行一次**反应掷骰\(14\)**，失败时受到**1d12\+2魔法**伤害，并暂时处于*脆弱*，直至**GM花费1恐惧点聚焦该目标**



**闪光飞刀 2d12**

**标记1点压力**，选择**远距离**内一点，如果没有阻挡，飞刀会在命中后发出由你选择形态的闪光，不断闪烁的光芒可以在**远距离**内清晰可见，闪光持续到**场景结束**或**一个生物触碰飞刀**



**爆能卷轴 2d12**

选择**远距离**内一个目标，进行一次**施法掷骰**，成功后，对目标造成**2d10\+5魔法**伤害，并被**推离一级距离**



**高级佳肴 2d12**

在**休整**时，**恢复共计3点的生命或压力**



**结缘花茶 2d12**

**长休时**，所有饮入花茶的生物都会一起在梦中创造一件美好的记忆，醒来后，各获得**一个缘梦标记物**，直到**下次长休前**，可以**花费一个缘梦标记物**而不是**花费1希望点**来**帮助盟友**，如果他们讲述一段在梦中共同创造的美好记忆，将帮助骰改为**d8**

**透视薄膜 2d12**

将薄膜附在固体表面上，会将对应区域暂时变得透明，薄膜被揭下后无法再次使用



**围炉烛火 2d12**

在**休整**时，点燃烛火，如果你在蜡烛燃尽前讲述一个故事，你及你的盟友**获得1希望点**



**琉璃浮花 3d12**

这朵水晶质感的花朵会悬浮在你身边，浮花上有**5个花瓣标记物**，当你**花费希望点**时，每**移除1个特殊标记物**可以代替**花费1希望点**



**辉光之镜 3d12**

当你**使一个目标恢复生命**时，你可以**花费1希望点**使其**邻近范围**内所有盟友同时**恢复1点生命**，随后镜子碎裂



**沥血之镜 3d12**

当你**标记生命点**时，你可以**标记1点压力**，使对你造成伤害的目标立即**标记等量点生命**，如果这会使目标死亡，你**恢复1点生命**，随后镜子碎裂



**守护鳞片 3d12**

**花费3希望点**，在你身边召唤一面笼罩你周围的虚幻护盾，护盾上具有**5个守护标记物**，当**你**或**邻近范围**内的盟友受到伤害时，可以**花费1个守护标记物**将伤害造成的**严重程度降低一级**



**皇室佳肴 3d12**

在**休整**时，**恢复共计4点的生命或压力**



**苦痛之息 4d12**

因极端悲痛而死之人所呼出的最后一口气

你必须**标记你所剩下的所有压力点**，然后使用你**最低的属性调整值**，进行一次**行动掷骰**对抗**邻近距离**范围内所有敌人的难度，你**每标记一点压力**都会使本次掷骰获得**\+2**加值，每个你对抗成功的目标需**标记1d4\+你标记的压力点**，每个你对抗失败的目标仅**标记1d4点压力**



**屠杀剑 4d12**

这一剑毁灭的不只是敌人

选择**近战范围**内一个目标，如果其难度不高于16，**标记2点压力**，目标立即标记**所有生命值和压力点**



**悔恨之尖 4d12**

尖锐的痛苦造就今日的行为

当你进行一次**动作掷骰失败**时，你可以描述过去一件对你产生重大影响的失败经历，然后你可以重新掷骰，并使用**d20**代替你的希望骰和恐惧骰。

之后，如果你**掷骰成功**，悔恨之尖会无害地永久扎入周围一处空间；如果你仍然**掷骰失败**，悔恨之尖会无害但痛苦地扎入你的身体，直至**下次长休后**，你可以拔出悔恨之尖并可以再次使用



**疗愈圣令 5d12**

如果你知道自己有第二条生命，你会做什么

**花费2希望点**，选择**极远范围**内一个目标，**恢复全部生命值，清除全部压力点**



**命运之泪 5d12**

传说中，命运女神在预见命定中的悲剧时会流下一滴眼泪，给予凡人一个机会

在**你**进⾏**行动掷骰**后，**花费3希望点**，你可以重新掷⼆元骰，并在掷骰结果中获得**\+10**
