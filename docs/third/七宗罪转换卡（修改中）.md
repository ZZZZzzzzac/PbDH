# 罪孽点

> 每一个罪人都有其原罪所在。
> 
> 这并不是缺点，反而是其真实的本质。
> 
> 世间都在教唆改善缺点，远离原罪，殊不知却使他们离真实越来越远。
> 
> 

每当罪人去拥抱罪孽，或GM触发其罪孽之时，罪人角色获得一点罪孽点，并将一个罪孽骰置于其角色卡上。（最大数量不超最大的属性值）

## 罪孽骰

在角色进行投掷之前，你可以花费一点罪孽点，将罪孽骰加入此次投掷之中，并将其的出目加于恐惧骰的结果上。

## 升华

每一次你在拥抱罪孽之后，你可在罪孽钟上标记一个焦点，当罪孽钟进度标满的时候，你可以进行升华仪式。

完成升华仪式之后，你可以进行升阶。

## 透支

当你罪孽钟表标满之时，可以花费与你位阶相同的罪孽点，在下次行动时，获得下一位阶的特性。
